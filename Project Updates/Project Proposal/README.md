# Project Proposal

- `neural-symbolic-proposal.tex`: proposal source.
- `neural-symbolic-proposal.pdf`: compiled proposal.
- `neural-symbolic-references.bib`: proposal references.
- `figures/`: original pipeline diagram and editable Excalidraw source.
- `Template/`: original course template, sample bibliography, class, guide, and PDF.

```sh
latexmk -pdf neural-symbolic-proposal.tex
```

in the P1 report.
